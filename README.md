# Letter Tabs 1.0.0

Мод для Sine у Zen: прибирає favicon із вкладок, а в Essentials показує одну літеру. Вибрана плитка має контрастну літеру, неактивні — приглушену. Розміри плиток успадковуються від поточної теми Zen.

Двічі клацни Essentials → введи символ → OK. Порожнє поле повертає автоматичну першу літеру домену (youtube.com → Y). Зберігається один графемний символ, зокрема emoji. Літера прив’язана до адреси сайту й контейнера; Essentials того самого сайту в тому самому контейнері використовують спільну літеру. Збереження локальне, у налаштуванні `zen.letter-tabs.overrides`.

Подвійний клік по Essentials замінює стандартну дію Zen. Іконки папок, робочих просторів і керування звуком не змінюються. Назви вкладок не перейменовуються.

## Встановлення

Пакет містить `theme.json`, `chrome.css` і `LetterTabs.uc.js`. Для встановлення через GitHub опублікуй ці файли в корені окремого репозиторію та додай адресу через Sine. JavaScript для неофіційних модів має бути дозволений у Sine.

Для поточного локального профілю інсталятор `install.py` копіює пакет, додає Letter Tabs до реєстру Sine та CSS-імпорт. Перед змінами він зберігає резервні копії змінених файлів. Запускай його після повного закриття Zen. Після встановлення запусти Zen знову.

Вимкнення: Settings → Sine Mods → Letter Tabs. Налаштування літер залишаються для повторного ввімкнення.

Перевірено синтаксис JS і логіку автоматичних літер, Unicode, збереження, скасування, скидання та cleanup у тестовому оточенні. Візуальна перевірка в активному Zen ще потрібна.
