# Letter Tabs 1.1.1

Мод Sine для Zen. Звичайні вкладки без favicon: висота 32px, лівий відступ 14px, менші кнопки закриття та unload (гліф 10px у кнопці 20px).

Essentials: літера 13px, без декоративної обводки й тіні активної плитки. Подвійний клік відкриває поле прямо у плитці. Enter або клік назовні зберігає; Esc скасовує. Порожнє поле відновлює першу літеру домену. Unicode та emoji підтримуються. Символ зберігається для сайту й контейнера в `zen.letter-tabs.overrides`.

Прибрано кнопку Back to pinned URL, її пункт контекстного меню та індикатор зміненої адреси. Обробники ручного reset вимкнені на час роботи мода; виклики unload через менеджер очищають reset із поведінки.

Перейменовані назви фіксуються через `zenStaticLabel` і додаткове збереження в SessionStore окремо для кожної вкладки. Навігація не має змінювати їх. Нове перейменування замінює фіксовану назву; порожнє перейменування повертає динамічну. Якщо стару назву вже втрачено до встановлення 1.1, перейменуй вкладку один раз знову.

Для поточного профілю: `install.py` встановлює файли та реєструє мод у Sine з резервними копіями. Після оновлення повністю перезапусти Zen. Вимкнення — Settings → Sine Mods → Letter Tabs.

Перевірено синтаксис і mock-тести: inline-редагування, Enter/Esc/blur, скидання, фіксація назви після зміни, перейменування, вимкнення reset і cleanup. Візуальна перевірка в запущеному Zen не виконувалася.

## Виправлення 1.1.1

Виправлено шлях до SessionStore у нових версіях Zen. Додано fallback для старих версій і обробку помилок збереження, щоб основні функції продовжували працювати. Якщо SessionStore недоступний, додаткова фіксація назв працює в пам’яті поточного вікна.

GitHub: заміни `LetterTabs.uc.js`, `chrome.css`, `theme.json`, `README.md` у корені репозиторію. У Sine перевір оновлення, після чого повністю перезапусти Zen. У списку модів має бути версія 1.1.1.
